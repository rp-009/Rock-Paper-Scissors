# Rock Paper Scissors

A simple, interactive web-based Rock-Paper-Scissors game built using HTML, CSS, and vanilla JavaScript.

## Live Demo

🌍 **[Play the Game Here]([https://www.google.com/search?q=%23](https://github.com/rp-009/Rock-Paper-Scissors))** 
## Features

* **Play Against the Computer:** The game generates a random computer move using JavaScript's `Math.random()`.
* **Score Tracking:** A live scoreboard keeps a running tally of the user's score versus the computer's score.
* **Dynamic Visual Feedback:** The message container updates to display the outcome of each round, changing its background color to green for a win, red for a loss, or navy blue for a draw.
* **Interactive UI:** Features a clean flexbox layout with circular, clickable image choices that highlight upon hovering.

## Project Structure

* `rpc_index.html`: Contains the main structure, including the game choices, scoreboard, and message container.
* `rpc_style.css`: The stylesheet providing the layout, colors, and responsive flexbox alignment.
* `rpc_script.js`: The game logic that handles DOM manipulation, winner calculation, and score updates.
* `/images`: A directory containing the `rock.png`, `paper.png`, and `scissors.png` image assets used for the game buttons.

## How to Run Locally

1. Clone this repository to your local machine.
2. Ensure the `images` folder and the code files are in the same root directory.
3. Open `rpc_index.html` in any modern web browser to start playing.
